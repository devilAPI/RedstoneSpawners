# RedstoneSpawnersReloaded
This is [Trophonix's RedstoneSpawner](https://github.com/Trophonix/RedstoneSpawners) plugin, updated to the latest Minecraft version (1.16.5 – 26.3) and fixed a bug where spawners couldn't be powered with Redstone Torches, Blocks etc., only Redstone Dust.
## What is this?
RedstoneSpawnersReloaded is a very simple plugin which makes Mob Spawners toggleable via a redstone signal.
## Commands
| **Command** | **Info**                  | **Permission**         |
|-------------|---------------------------|------------------------|
| /rss        | Main Command. Shows help. | redstonespawners.admin |
| /rss reload | Reloads the config file.  | redstonespawners.admin |
